embedded_audio_processing_system/

pwm-based audio playback on stm32 via timer-driven signal generation; python fft/stft preprocessing and digital filtering for accurate note extraction.

% cat embedded_audio_processing_system/README

stack: C, STM32, PWM, interrupts, Python

  • plays melodies on a passive buzzer with hardware pwm: each note's frequency is set through the timer's auto-reload register (arr = timer clock / frequency − 1), and the duty cycle sets volume.
  • built an offline python pipeline that turns audio into firmware arrays: harmonic-percussive separation and a 4th-order butterworth bandpass (250–1000 hz) to strip noise from main melody, a 4096-point stft, per-frame peak detection, then merging frames within ±2 hz and dropping notes under 80 ms. the output is copied into firmware as const frequency and duration arrays.
  • the mcu is built for deterministic timing and waveform generation while the offline python host allows large fft windows and heavier noise reduction while playback stays simple and repeatable.

fun fact: i actually used bits of this code to play christmas themed soundtracks on the HEATSeeker robot since we presented the project before winter break :D
